## 📚 Overview

This project presents a complete research paper investigating whether Google Search Console performance metrics can be used to identify content with a higher likelihood of receiving search clicks.

The paper includes:

- Abstract
- Introduction
- Dataset Description
- Methodology
- Results
- Limitations
- Ranked Recommendations
- Reproducibility
- Acknowledgments

The research was developed using the FlyRank ML Internship dataset and follows public-safe research practices.

## 📊 Research Summary

**Research Question**

> Can Google Search Console performance metrics be used to identify content with a higher likelihood of receiving clicks and support content optimization decisions?

The project evaluates a Random Forest Classifier against a rule-based baseline using anonymized Google Search Console performance data from the FlyRank ML Internship dataset.
